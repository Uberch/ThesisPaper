\begin{abstract}

Rzk is an Interactive Theorem Prover (ITP) designed for formalizing modern mathematics,
featuring a built-in language server.
However, its existing feedback loop is slow and relies on explicit user actions.
This paper presents the design, implementation, and evaluation of an enhanced LSP server for Rzk.
The proposed architecture introduces advancements to type-checking and caching mechanisms,
enabling the typechecker to read unsaved IDE buffers, compute diagnostics incrementally,
and update them dynamically in response to user input.
\end{abstract}
